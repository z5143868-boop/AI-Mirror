# Product Requirements Document: AI Mirror - 人物关系顾问 & 心理镜像系统

## 1. Product Overview
AI Mirror 是一个具备深度心理洞察、长期记忆和自我进化能力的“数字孪生”顾问系统。
该产品旨在通过深度心理访谈、潜意识投射测试和长期记忆机制，帮助用户探索自我人格、解析潜意识动力，并提供定制化的长期关系建议与心理咨询。

## 2. Core Features

### 2.1 User Roles
| Role | Registration Method | Core Permissions |
|------|---------------------|------------------|
| 普通用户 | 匿名/账号注册 | 完整体验心理访谈、测试、报告生成及长期顾问服务 |

### 2.2 Feature Module
AI Mirror 的核心功能主要分布在以下关键页面：
1. **引导与初始化页 (Onboarding)**: 收集基础信息，进行初步 MBTI 判定。
2. **聊天访谈页 (Chat Stream)**: 核心交互界面，包含深度访谈、实时状态反馈、嵌入式场景测试。
3. **深度测试页 (Assessment)**: 阴影探索与生活场景测试，采用卡片式交互。
4. **报告与顾问页 (Report & Consultant)**: 展示深度分析报告，并作为长期顾问模式的入口。

### 2.3 Page Details

| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| **引导与初始化页** | 基础信息采集 | 表单收集用户的称呼、年龄、性别、职业（支持联想输入）、收入范围。 |
| | MBTI 判定路径 | 提供直接选择 MBTI 类型或进入 AI 生成的 5 道二选一生活场景题进行判定。 |
| **聊天访谈页** | 智能对话系统 | 模拟资深心理分析师，使用 CoT (思维链) 逻辑，先分析情绪再追问；支持流式输出 (Streaming)。 |
| | 状态反馈机 | 显示 AI 当前状态：Thinking (分析情绪/生成场景)、Streaming (打字机输出)、Hinting (闲置 >10s 浮现建议气泡)。 |
| | 记忆系统 (后台) | 采用滑动窗口摘要 (Sliding Window Summary)，每 15 轮对话触发后台总结，更新用户画像。 |
| | 嵌入式组件 - 标签云 | 在对话流中渲染 50 个性格关键词气泡，用户点击即可存入画像。 |

| **深度测试页** | 阴影探索 (Shadow Work) | 基于用户的恐惧点生成直击痛点的问题。采用 Tinder 式卡片交互：左滑(否认/跳过)、右滑(承认/确认)。 |
| | 进度反馈 | 页面角落常驻“镜像粒子球”，随着测试数据的完善，球体从模糊变清晰、明亮。 |
| **报告与顾问页** | 报告生成链 | 分步展示生成过程：大纲 -> 核心人格 -> 潜意识动力 -> 关系建议 -> 完整报告。 |
| | 互动报告 | Markdown 渲染完整报告 (>1500字)，支持点击高亮关键词弹出 Tooltip 解释心理学原理。 |
| | 长期顾问模式 | 报告生成后，自动切换为“全知顾问”模式，注入完整画像摘要作为背景知识进行后续对话。 |

## 3. Core Process

### 核心用户流程

1. **初始化**: 用户进入，填写基础资料，确定 MBTI。
2. **深度访谈循环**: 进入聊天页，AI 进行访谈，间歇性触发“标签云选择”和“场景模拟”。
3. **专项测试**: 针对特定痛点进入“阴影探索”卡片测试。
4. **生成报告**: 数据积累达标后，触发长文本报告生成。
5. **长期陪伴**: 报告生成后，进入长期顾问模式，基于历史记忆提供持续咨询。

## 4. User Interface Design

### 4.1 Design Style
*   **主色调**: 深海蓝 (Deep Ocean) + 荧光白 (Glow)，营造沉浸、神秘且理性的心理咨询氛围。
*   **核心隐喻**: “镜像粒子球” (Progress Orb)。初始模糊暗淡，随着对用户了解加深，逐渐清晰明亮。
*   **交互风格**: 桌面端优先 (Desktop-First)，兼容移动端。强调流畅的微交互（如卡片滑动、震动反馈、打字机效果）。

### 4.2 Page Design Overview

| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| **全局** | 导航与状态 | 顶部/侧边简洁导航，右下角常驻“镜像粒子球”作为进度指示器。 |
| **聊天访谈页** | 对话流 | 气泡式对话，AI 思考时显示具体状态文案（如“正在分析情绪...”）。输入框长时间未动时，上方浮动 3 个建议气泡。 |
| **深度测试页** | 卡片交互 | 屏幕中央大卡片设计 (Tinder-style)。左滑红色调(否认)，右滑绿色调(承认)。配合轻微震动反馈。 |
| **报告页** | 动态文档 | 类似 Notion 的文档流布局。生成过程中显示 Check list 动画（正在解析潜意识... [OK]）。 |

### 4.3 Responsiveness
*   **策略**: Desktop-first (桌面优先)，但关键交互（如卡片滑动）需适配触摸操作。
*   **布局**: 桌面端采用分栏布局（左侧导航/状态，中间主内容，右侧摘要/工具箱）；移动端流式布局，侧边栏折叠。
